# Roomfinder

## Descripcion

RoomFinder es un producto digital, compuesto por una Landing Page informativa y una Web Application responsive, que conecta a estudiantes que buscan una habitación con quienes tienen una disponible: desde el dueño de una vivienda que alquila cuartos hasta el estudiante que ya alquila y busca un roomie porque no puede cubrir el gasto solo.

## Documentacion

La documentacion del proyecto se encuentra disponible en la carpeta `Documentacion/`.
Adicionalmente, el diseño de las paginas debe basarse en los diseños realizados previamente en Figma.
La documentacion archivada en formato .DOCX NO esta sincronizada con el documento en drive, por lo tanto, si el documento descargado es mas antiguo que 48 horas, se le debe notificar al usuario para verificar que no habran cambios sin sincronizar.

## MCPs

Los MCPs a utilizar son:
- Figma MCP
- Chrome CDP MCP

En caso de que su entorno no tenga dichas MCPs disponible, informele al usuario para su instalacion antes de continuar con el desarollo del proyecto.
