# RoomFinder

Sitio web responsivo de RoomCo donde estudiantes universitarios encuentran habitaciones cerca de su campus y anfitriones las publican.

## Tecnologías
- HTML5
- CSS3

## Cómo trabajar
Lee [SPEC.md](SPEC.md). Cada pantalla se hace en su propia rama `feature/...` creada desde `develop`, y vuelve a `develop` con un Pull Request revisado por un compañero.
